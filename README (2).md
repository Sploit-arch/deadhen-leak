# DeadHEN --- Source Release

> **A public release of the source I originally provided and the work I
> contributed.**

## Why this is being released

Since apparently speaking up about the issues was a problem, I'm
releasing the source publicly.

The base I supplied was working: the jailbreak ran, Debug worked, the
requested features were present, and it was not suffering from the same
crashing issues being discussed later. I also contributed fixes and
additional functionality to help get the project working.

The conversations around this project make the situation pretty clear:
settings were being added and adjusted, some options were hard-coded,
and changes were being made without a complete understanding of how they
affected the existing code. The result was more problems being
introduced into a base that had already been working.

So here's the source. It's available for people to inspect, learn from,
and use in accordance with the applicable rights and permissions.

## What this release represents

-   The original base I supplied for the project.
-   Work and features I contributed.
-   Fixes made to address issues affecting the jailbreak.
-   The project source as it existed at the time of release.

This is not a claim that every line of the project was written by me.
Contributions should be credited accurately, and existing third-party
notices should remain intact.

## A note to the project

You wanted the base and the features. I put in the work, helped get
things running, and fixed issues that were causing problems.

Now that things have turned into this, I'm done keeping my contributions
behind closed doors. The source is out in the open. Anyone can look at
what was changed and make up their own mind.

**Enjoy the source. I'm moving on.**
